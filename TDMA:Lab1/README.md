# Численное решение краевой задачи методом прогонки

##  Описание проекта

В данной лабораторной работе реализуется численное решение краевой задачи для обыкновенного дифференциального уравнения (ОДУ) второго порядка с использованием **разностной схемы** и **метода прогонки** (Tridiagonal Matrix Algorithm).

Проект включает проведение вычислительного эксперимента для оценки точности, вычислительной устойчивости и производительности алгоритма на последовательно сгущающихся сетках (вплоть до $N \approx 10^6$ узлов).

##  Постановка задачи

Дано линейное ОДУ второго порядка:


$$12u''(x) - 5u(x) = 2110 - 450x^2, \quad x \in [0, 1]$$

С заданными краевыми условиями первого рода:


$$u(0) = 10, \quad u(1) = 100$$

Для проверки корректности численного решения и расчета глобальной погрешности используется известное точное (аналитическое) решение:


$$u(x) = 10 + 90x^2$$

##  Разностная схема и СЛАУ

Отрезок интегрирования $[0, 1]$ разбивается на $N$ равных участков с шагом $h = \frac{1}{N}$. Вводятся узлы сетки $x_i = i \cdot h$.
Вторая производная аппроксимируется центральной конечной разностью второго порядка точности:


$$u''(x_i) \approx \frac{v_{i-1} - 2v_i + v_{i+1}}{h^2}$$

После подстановки в исходное ОДУ задача сводится к системе линейных алгебраических уравнений (СЛАУ) с трехдиагональной матрицей:


$$A_i v_{i-1} - C_i v_i + B_i v_{i+1} = -F_i$$

Где коэффициенты для внутренних узлов ($i = 1, \dots, N-1$) равны:

* $A_i = B_i = \frac{12}{h^2}$
* $C_i = \frac{24}{h^2} + 5$
* $F_i = 450x_i^2 - 2110$

Из краевых условий получаем: $v_0 = 10, v_N = 100$. Матрица удовлетворяет условиям строгого диагонального преобладания ($\vert{}C_i\vert{} > \vert{}A_i\vert{} + \vert{}B_i\vert{}$), что гарантирует существование, единственность решения и вычислительную устойчивость метода прогонки.

##  Особенности реализации (C++)

В проекте реализовано два подхода к решению сформированной СЛАУ, чтобы продемонстрировать влияние микроархитектурных и математических оптимизаций на скорость работы:

### 1. Универсальная реализация

* **Память:** $O(N)$. Ленты матрицы ($A, B, C$) и вектор правой части ($F$) хранятся в виде динамических массивов `std::vector`.
* **Применимость:** Подходит для решения ОДУ с переменными коэффициентами.
* **Специфика:** Выполняет "честный" расчет по классическим формулам прямого и обратного хода прогонки со всеми операциями умножения и деления.

### 2. Оптимизированная реализация

* **Память:** $O(1)$ для хранения коэффициентов матрицы. Учитывая специфику текущей задачи (константные коэффициенты при производных), $A, B$ и $C$ не зависят от узла $i$ и вынесены в константы. Правая часть $F_i$ вычисляется процессором "на лету" без сохранения в память.
* **Математическая редукция:** Исходное уравнение разделено на $A$. Так как $A = B$, коэффициенты боковых диагоналей становятся равны $1$, что полностью исключает их из формул расчета прогоночных коэффициентов $\alpha$ и $\beta$.
* **Микрооптимизация (ALU):** Самая дорогая операция для процессора (деление с плавающей точкой) сокращена до одного раза за итерацию путем замены деления на умножение на обратную величину знаменателя.

##  Вычислительный эксперимент

Для каждой сетки вычисляются следующие метрики:

1. **Глобальная погрешность:** $\max \vert{}u_i - v_i\vert{}$ — максимальное отклонение численного решения от эталонного аналитического.
2. **Максимальная невязка:** $\max \vert{}r_i\vert{}$ — мера точности удовлетворения исходной СЛАУ найденным вектором $v$.
3. **Время выполнения ($t$, мс):** Измеряется с помощью высокоточного таймера `std::chrono::high_resolution_clock` без учета накладных расходов на I/O.

Эксперимент демонстрирует, что метод обладает высокой **вычислительной устойчивостью**: несмотря на колоссальный рост коэффициентов при сгущении сетки (из-за деления на $h^2$), ошибка машинного округления типа `double` не возрастает лавинообразно, оставаясь на уровне $10^{-13} \dots 10^{-11}$.
